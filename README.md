# 📚 React Book List App

A React application that displays a paginated list of books with the following features:

- 🔍 Search (with debounce)
- 🔄 Infinite Scroll (pagination)
- ↕️ Sorting 
- 🌀 Loading spinner
- 🧠 Lazy loading with `React.Suspense`


## 🧰 Tech Stack

- React (w/ hooks)
- Axios
- CSS Modules
- Lazy loading (`React.lazy`)
- Intersection Observer API
